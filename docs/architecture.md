# Architecture

Next.js App Router site + Payload CMS in one app. All source lives in `src/`.

## Layout

- `src/app/(site)/` - public site: home, `/posts`, `/posts/[slug]`. `SiteWrapper.tsx` composes Header, Footer and `LanguageProvider`.
- `src/app/(payload)/` - Payload admin (`/admin`), REST (`/api/[...slug]`) and GraphQL (`/api/graphql`). Generated by Payload; don't hand-edit.
- `src/collections/` - Payload collection configs.
- `src/components/` - UI components; `animations/` has a barrel `index.ts`.
- `src/lib/` - `i18n.tsx` (locale context), `fetcher.ts` (SWR fetcher).

## Collections

- **Posts** - title, excerpt, content (Lexical richText) are localized (en/pt-BR). `slug` unique, auto-generated from title in a `beforeChange` hook. `status` draft/published, `publishedAt`, `coverImage` -> media, `category` -> categories. Anonymous users read only published posts.
- **Categories** - name, description localized; `slug` unique. Public read.
- **Media** - uploads to `public/media`, images only, 5MB max, `alt` required. Public read.
- **Users** - Payload auth (JWT). `role` admin/editor (default editor) saved to JWT. Only admins create/delete users or change roles.

## Data flow

- Post page (`posts/[slug]/page.tsx`) is a server component that fetches `/api/posts?where[slug][equals]=...&depth=1` with `revalidate: 60` and calls `notFound()` on miss.
- Home and posts list fetch client-side with SWR (`HomePostsSection.tsx`, `PostsPageContent.tsx`).
- Lexical JSON is rendered by a custom recursive renderer in `PostPageContent.tsx` (format bitmask: `format & 1` = bold, etc.).
- Image URLs are built as `/media/{filename}` and served through `next/image`.

## Theme

An inline script in the `(site)` layout head reads `localStorage.theme` before paint. It adds `dark` to `<html>` (theme=dark, or system preference). `globals.css` swaps CSS variables (`--background`, `--foreground`, `--highlight`) on `.dark`. `ThemeToggle` is loaded with `next/dynamic`.

## i18n

Client-side only. `LanguageProvider` stores the locale in localStorage; components call `t()` from `useLanguage()`. Translation keys are typed from the `en` dictionary.
